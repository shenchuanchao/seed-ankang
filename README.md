# 山水安康 · 可交互三维全景

依据公开地图资料构建的低多边形（low-poly）3D 旅游全景沙盘，呈现陕西安康的**一江（汉江）一湖（瀛湖）**与巴山群峰。
全程使用 Three.js 实时渲染，**无需联网、无外部 API、无需地图密钥**。

> **项目来源**：本项目由 [ruanyf/seed-westlake](https://github.com/ruanyf/seed-westlake)（阮一峰用豆包 Seed Evolving 模型生成的交互式 3D 西湖地图）改造而来。
> 改造方式为**保留渲染引擎、全量替换地理与内容数据**：引擎层（Three.js 场景、低多边形建模、相机弧线飞行、小地图、三时辰光照、拍照导出）原样复用，地理/景点/文案层重写为安康。
> 原项目的视觉风格取自 `hangzhou.mp4` 中的《山水杭州》空间地图，该文件保留在本仓库以注明出处。

## 打开方式

直接双击 `index.html`，用 **Chrome / Edge** 打开即可（Three.js 已内嵌在 `lib/` 目录，可完全离线运行）。

## 收录景点（12 处）

- **安康八景**：瀛湖、汉江、南宫山、香溪洞、龙舟文化园
- **富硒茶山**：紫阳富硒茶、凤凰山、鬼谷岭
- **峡谷溶洞**：千层河、双龙溶洞
- **城市名片**：安康博物馆、安澜楼

## 场景特色

- 按真实经纬度等比投影生成的**瀛湖岸线、翠屏岛、汉江主河道**，以及**汉江大桥、安澜桥**两座跨江通道；
- 高原点坐标取自公开近似值，场景中心位于瀛湖与安康城区之间（`ORIGIN = [108.85, 32.60]`）；
- 南宫山、凤凰山、鬼谷岭、千层河、香溪洞山、牛山、龙王山等**低多边形山峦**，山体用高斯丘 + 山麓台地压平算法，建筑落位平整、不悬空；
- **富硒茶园台地**：紫阳富硒茶园、平利富硒茶、南宫山台地、香溪洞台地（对应安康「中国硒谷」产业带）；
- 汉江北岸**安康城区**程序化楼群（滨江低层、江畔略高），与江中游船、涟漪、飞鸟等动态细节；
- **城区主要道路与路名**：滨江大道、安康大道、汉江路、316 国道；
- 道路名随缩放自动淡入淡出，右下角小地图同步绘出瀛湖、汉江、道路与全部景点；
- 三种时辰光照（晴昼 / 日落 / 夜游），夜景含万家灯火。


## 景点配图怎么放

引擎已实现 **「优先真实照片 → 缺失自动回退程序化占位图」**：把图片按 **`assets/photos/<景点 id>.jpg`** 命名丢进去即生效，**无需改任何代码**。

⚠️ 用的是 `data.js` 里景点的 **`id`（全小写英数）**，不是中文名。

| 景点 | 应放的文件 | 景点 | 应放的文件 |
| --- | --- | --- | --- |
| 瀛湖 | `assets/photos/yinghu.jpg` | 鬼谷岭 | `assets/photos/guigu.jpg` |
| 汉江 | `assets/photos/hanjiang.jpg` | 千层河 | `assets/photos/qianhe.jpg` |
| 南宫山 | `assets/photos/nangong.jpg` | 双龙溶洞 | `assets/photos/shuanglong.jpg` |
| 香溪洞 | `assets/photos/nanxi.jpg` | 凤凰山 | `assets/photos/fenghuang.jpg` |
| 龙舟文化园 | `assets/photos/longzhou.jpg` | 安康博物馆 | `assets/photos/bowuguan.jpg` |
| 紫阳富硒茶 | `assets/photos/chashi.jpg` | 安澜楼 | `assets/photos/anlan.jpg` |

例如**安澜楼**的照片就命名为 **`anlan.jpg`**，放进 `assets/photos/`。

建议尺寸 480×300 以上（详情卡按比例裁切），单张 200–600 KB。

## 已知待完善项

1. **`assets/photos/` 目录**：存放景点实拍图，按 `<景点 id>.jpg` 命名即自动生效，该景点缺图时自动回退为程序化占位图。目前已有 `anlan.jpg`（安澜楼）。目录内上游遗留的西湖照片（`leifeng.jpg` 等）与安康景点 id 不匹配，属无用文件，删除不影响运行。
2. **坐标为艺术化近似**：场景经等比压缩（`SCALE = 150`），非测绘级地图，亦非建筑精确复刻；如需更高精度可逐个校准地标经纬度。
3. **`hangzhou.mp4` 体积约 17MB**：作为上游出处留存。若需精简仓库，可在确认不再需要出处参考后移除（注意：仅删除文件不会缩小已有 Git 历史体积，需重写历史）。

## 用途说明

本项目为**城市形象与文旅可视化展示**原型。若用于含硒产品溯源场景，可在现有骨架上把「景点点位」扩展为「富硒产区 / 基地点位」，并将详情卡字段改为硒含量、检测批次、企业与溯源链路。
